## Holberton-Simple-Shell

# Collaboration by Ethan and Sijin

# Description
This is an implementation of a simple shell environment (STC)

# Requirements
* GCC compiler
* Ubuntu 22.04 (Holberton based sandbox)
* C standard -> gnu89

# Compilation
* gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hsh
